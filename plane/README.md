# PLANE

Profile-guided Link Allocation for Networked Experts.

PLANE turns MoE router traces (FLAME-MoE, OLMoE) or Chakra execution traces into per-layer source-to-destination byte matrices, builds a reservation `E` (uniform, mean, P95, worst) and admits `min(M, E)`. It hands the admitted byte matrix, ranks and bytes only, to the planner, which picks Clos paths and rates. The planner never sees tokens; deflection and envelope policy stay in PLANE.

## Requirements

- Python 3.12 environment, created from the repository root with `uv sync --extra dev`.
- Requires the group's network planner (Puppeteer, unpublished, not distributed with this repository) installed as the `puppeteer` package.

## Commands

```bash
plane profile --source flame --layer layer_02 --window 4 --reservation p95 -o plane/output/prof
plane plan --matrix plane/output/prof/reservation.npy -o plane/output/plan
plane plan --matrix plane/output/prof/reservation.npy \
  --route-matrix plane/output/prof/hist_0.npy -o plane/output/plan-i
plane replay --reservation-file plane/output/prof/reservation.npy --tau 0.03 -o plane/output/replay
plane export-et --matrix plane/output/replay/sent.npy -o plane/output/et
plane profile-et --trace run-0/ --trace run-1/ --reservation p95 \
  -o plane/output/et-profile
plane plan --matrix plane/output/et-profile/reservation_bytes.npy \
  --route-matrix plane/output/et-profile/mean_bytes.npy --already-bytes \
  -o plane/output/et-plan
plane experiment --suite all -o plane/output
plane experiment --suite claim-v1 -o plane/output
plane experiment --suite clos-baselines -o plane/output
python plane/scripts/flagship_stage1.py
```

`plan` routes from `--route-matrix` (mean matrix) and sizes from `--matrix` (P95 or worst). `export-et` writes Chakra SEND/RECV files from a decided (post-deflect/drop) matrix for ASTRA-sim 2.0. `profile-et` pairs Chakra SEND/RECV records and sums off-rank bytes into one matrix per `--trace` directory; traces with collectives also need `--topology`; its matrices are already bytes, hence `--already-bytes` on the following `plan`.

## Layout

| Path | Contents |
|---|---|
| `moe_feeder/` | Python package: loaders, policy, admission, planner glue, experiment suites, CLI (`plane`) |
| `scripts/` | Figure and sanity scripts (`flagship_stage1.py` and the other report scripts) |
| `tests/` | pytest tests |
| `configs/` | `topology_8gpu_clos.yaml`, the Clos topology |
| `reports/` | Measured results (below) |
| `figures/chapter6/` | Thesis figure scripts and rendered figures |
| `output/` | Generated by the commands above; gitignored |
